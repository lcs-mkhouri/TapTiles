# Tap Tiles

Tap Tiles is a macOS rhythm game built with SwiftUI. Choose a bundled song, press the matching keys as tiles reach the target line, maintain combos, and finish the track to win.

## Features

- Four selectable songs with bundled audio
- Song-synchronized falling tiles
- Keyboard controls for four lanes
- Volume control
- Live score, accuracy, combo, best score, and letter rank
- Health, pause, replay, game-over, and win states
- In-app credits and audio license information

## Controls

| Lane | Key |
| --- | --- |
| 1 | Left Arrow or A |
| 2 | Up Arrow or S |
| 3 | Down Arrow or D |
| 4 | Right Arrow or F |

Press **Start Game** or **Play Again** from the board overlay. Use the **Pause** button to pause both the tiles and the selected song.

## Building

Open `TapTiles.xcodeproj` in Xcode and run the **TapTiles** scheme on macOS.
